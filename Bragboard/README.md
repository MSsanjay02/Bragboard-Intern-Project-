# BragBoard 🏆

BragBoard is an internal employee recognition platform that allows team members to appreciate each other through shout-outs, reactions, and comments.

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: FastAPI
- Database: PostgreSQL
- Auth: JWT (Access & Refresh)

## Features
- Employee shout-outs
- Tagging teammates
- Reactions & comments
- Admin dashboard & analytics

🚧 In progress – built from scratch
